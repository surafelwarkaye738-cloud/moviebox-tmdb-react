# Netflix Clone — React + TMDB

A modern Netflix-inspired movie discovery application built with React.js and the TMDB API.

This project was created as an educational and portfolio project to demonstrate frontend development, REST API integration, reusable React components, routing, responsive UI design, state management, browser storage, search, movie details, and trailer playback.
